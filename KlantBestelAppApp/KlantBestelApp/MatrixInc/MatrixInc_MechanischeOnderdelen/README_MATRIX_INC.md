# Matrix inc. - mechanische onderdelen webshop

Deze versie is een eenvoudige Razor Pages-webshop voor mechanische onderdelen. De site heeft een moderne webshopuitstraling met een duidelijke header, zoekbalk, categorieën, filters, productkaarten, productdetailpagina, winkelmand, inlogpagina met gastoptie en orderhistorie.

## Werkende onderdelen

- Producten bekijken
- Productdetail bekijken
- Product toevoegen aan winkelmand
- Bestelling plaatsen
- Orderhistorie bekijken

## Extra pagina's voor uitstraling

- Inloggen / doorgaan als gast
- Service
- Contact

## Mappenstructuur

- `Pages/Producten`: productoverzicht en productdetail
- `Pages/Winkelmand`: winkelmandoverzicht
- `Pages/Bestellingen`: bestelling plaatsen en orderhistorie
- `Pages/Account`: decoratieve inlogpagina
- `wwwroot/css/...`: CSS per pagina in eigen map
- `DataAccessLayer/Models`: Nederlandse modelklassen

## Belangrijk

De website is bewust eenvoudig gehouden. De extra visuele onderdelen maken de site realistischer, maar de kern blijft overzichtelijk en goed uit te leggen.
