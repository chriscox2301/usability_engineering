# Technische code-uitleg

Deze versie bevat extra commentaar voor junior developers. De comments leggen uit:

- wat een constructor doet en hoe Dependency Injection parameters doorgeeft;
- wat `IActionResult` teruggeeft in controllers;
- hoe controllers gekoppeld zijn aan Razor Views;
- wat een model en ViewModel is;
- wat de properties/attributen van de models betekenen;
- hoe repositories `SqlConnection`, `SqlCommand` en `SqlDataReader` gebruiken;
- hoe forms met `asp-for`, `asp-action` en `asp-route-id` werken;
- hoe CSS-klassen gekoppeld zijn aan `.cshtml` views;
- hoe het mobiele hamburgermenu in `site.js` werkt.

De comments zijn technisch gehouden en beschrijven vooral MVC, data access, routing en binding.
